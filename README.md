# Green API Max Chat

Веб-приложение для отправки и получения текстовых сообщений через [Green API](https://green-api.com/) (мессенджер MAX). Интерфейс повторяет структуру [web.max.ru](https://web.max.ru/): список чатов слева, окно переписки справа.

## Возможности

- Ввод учётных данных Green API (`idInstance`, `apiTokenInstance`)
- Поиск контакта по номеру телефона и создание нового чата
- Отправка текстовых сообщений через метод `sendMessage`
- Приём входящих сообщений через `receiveNotification` (long polling)
- Отображение последнего сообщения

## Стек

- **React 19** + **TypeScript**
- **Vite** — сборка и dev-сервер
- **Tailwind CSS** — стили
- **Axios** — HTTP-клиент
- **Green API** — REST API мессенджера MAX

## Требования

- **Node.js** 18 или выше
- **npm** 9 или выше (или `yarn` / `pnpm`)
- Аккаунт [Green API](https://console.green-api.com/) с созданным инстансом

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Segizmund/green-api-chat.git
cd green-api-chat
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Запустить dev-сервер

```bash
npm run dev
```

Приложение откроется по адресу [http://localhost:5173](http://localhost:5173).

### 4. Собрать production-версию (опционально)

```bash
npm run build
npm run preview
```

## Как получить учётные данные Green API

1. Зарегистрируйтесь на [console.green-api.com](https://console.green-api.com/).
2. Создайте новый инстанс (кнопка **«Создать инстанс»**).
3. Откройте его — на главной странице увидите:
   - **`idInstance`** — например, `3100000001`
   - **`apiTokenInstance`** — длинный токен
4. Скопируйте их и введите на странице входа в приложении.

> **Важно:** инстанс должен быть авторизован (статус `authorized`) — иначе отправка и приём сообщений работать не будут. Авторизация занимает до нескольких минут после создания.

## Как пользоваться

1. Откройте приложение и введите `idInstance` и `apiTokenInstance` — нажмите **«Войти»**.
2. В левой панели нажмите кнопку **«+»** и введите номер телефона получателя (в формате `79991234567`) и укажите имя контакта.
3. После создания чата он автоматически откроется, после чего вы можете отправлять сообщения.
4. Ответ придёт автоматически — приложение опрашивает сервер Green API раз в 1.5 секунды.

## Структура проекта

```
src/
  api/            # Обёртки над REST API Green API
  components/     # UI-компоненты (ChatWindow, FindContactDropdown и др.)

  pages/          # ChatPage, страница входа
  types/          # TypeScript-типы
  utils/          # Утилиты (normalizeChatId, upsertChat, appendMessage translateGreenApiError)
```

## Известные ограничения

- Поддерживаются только **текстовые сообщения** (по условию).
- Приём сообщений реализован через **HTTP long polling** — при закрытой вкладке уведомления не приходят.
- Учётные данные хранятся **только в памяти** и не сохраняются между перезагрузками страницы.
